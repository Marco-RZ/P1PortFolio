Sistema de Inventario

ASP.NET C# SQL Server Bootstrap

Aplicación web para la gestión y control de inventario de una pequeña empresa. Permite registrar productos, proveedores, entradas y salidas de stock, así como generar reportes en tiempo real. Desarrollada con ASP.NET MVC y una base de datos SQL Server.

TaskTrack App

Android Studio Kotlin Firebase Room DB

Aplicación móvil Android para gestión de tareas y proyectos personales. Incluye sistema de categorías, recordatorios con notificaciones push, sincronización con Firebase y modo oscuro. Diseñada siguiendo los principios de Material Design 3.

BD Hospitalaria

MySQL SQL Modelado ER Normalización

Diseño e implementación de una base de datos relacional para la gestión de un hospital. Incluye el modelo entidad-relación, diagrama relacional, normalización hasta 3FN y procedimientos almacenados para consultas de pacientes, médicos, citas y expedientes clínicos.

Red Empresarial

Cisco Packet Tracer VLAN OSPF DHCP

Diseño y simulación de una red empresarial para una empresa mediana con dos sucursales. Configuración de VLANs por departamento, enrutamiento dinámico con OSPF, servidor DHCP centralizado, ACLs de seguridad y conexión WAN entre sedes, todo simulado en Cisco Packet Tracer.
